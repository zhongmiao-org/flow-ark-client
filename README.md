# FlowArk Client

通用 RPA 单机客户端。0.2.0 的业务模板、示例资料和模拟网站由独立 flow-ark-templates 仓库维护；应用首次启动不预装业务模板或示例流程。

模板使用：模板库 → 导入 .flowark-template.zip（或相同内容的 .zip）→ 核对来源声明与能力 → 安装 → 创建实例 → 配置并保存资源和动作授权 → 保存入口参数 → 运行。旧 JSON 模板明确不支持。多入口共享实例配置、状态；只检查当前入口需要的绑定。同版本不同摘要拒绝，新版本并存，采用新版建立新实例，资源与授权重新确认。

模板导出只包含定义；修改的流程导出为新本地身份。被实例、计划或历史引用的版本不能卸载。导入与配置均不执行脚本，不安装依赖或浏览器。JS/TS 脚本为可信代码，SDK 不是系统级安全沙箱。

本次本机开发数据清理由 scripts/maintenance/reset-local-work.mjs 显式执行，与普通用户启动和升级完全分离。详见治理仓库 docs/templates/acceptance.md。


通用的本地 RPA 工作台，用于编排、运行和查看自动化流程。当前为 **macOS Apple Silicon 0.3.0 开发候选**，尚未正式发版。

## 使用

首页采用统一 Figma 设计，显示本地流程、当天创建的运行、活动任务及待办数量。可按名称搜索、筛选最近七个日历日编辑或来自模板的流程，点击卡片的「打开」进入编排后运行。首次使用可直接创建空白流程或选择模板 ZIP；取消文件选择保留原页面。「使用指南」在右侧内置网页打开本仓库的使用说明，需要网络。

首次打开为空工作台，可创建普通流程或从模板库导入标准包。编辑器右侧提供通用节点、参数和资源绑定；业务字段来自模板包，通过独立的「实例配置」填写。普通流程不显示招聘配置。模板提供的运行参数在实例配置中统一编辑，右侧展示只读值；保存失败保留输入并显示原因，普通流程仍可自由编辑参数。

运行日志、调试预览和结果会遮盖已读取凭据，包括对象字段名；操作失败显示处理后的错误文字。旧历史中已轮换或无法识别的内容不会自动清理。

客户端不内置任何业务模板，示例和完整模拟网站由 flow-ark-templates 独立维护；没有上线模板商店。Chrome 的表单与上传通用流程已验证；macOS Chrome 153.0.8010.48 存在原生下载恢复崩溃，当前明确阻止自动下载，尚未修复该浏览器问题。Firefox、Safari、Windows 尚未验收。

编辑器点击「逐步调试」，运行会在首个节点前暂停。「执行下一步」实际执行一个节点入口，并显示下一个位置与输出预览；条件和循环会进入实际子路径。「继续」连续运行，「取消」停止并回收本次资源。运行绑定固定快照，修改草稿不会改变已开始的调试；失败不会自动重放。

运行结束并回收资源后，可在详情预览重新运行。默认采用原执行快照，也可明确选择当前已保存流程，并可逐步调试；核对已有输出与外部结果后，从首个节点创建关联的新运行。旧记录保持原样，已撤销的资源授权不会从历史恢复。同一次确认回复丢失时使用“重试此次确认”，不会再创建一个任务。

点击「长流程大纲」可按名称、步骤编号或动作类型搜索，展开所在分组和条件／循环分支；清单与流程图可切换。草稿与只读运行快照分别展示，「聚焦当前执行」只定位近期确认的实际执行步骤；循环的多次执行单独列出，编号不代表完成进度。查看运行详情后返回会保留大纲位置。画布的「聚焦所选步骤」恢复可读视图，参数输入保留手动缩放和平移。

Excel 的「字段映射 · 新建工作簿」操作提供完整编辑页：记录字段或数组索引映射到指定列，分别设置表头和文本／数字／布尔类型。预览验证所有可解析记录并显示前三行；运行期来源只标记待执行核对。空值保留、重复列与类型冲突阻止保存，输出只新建 `.xlsx`，同名文件存在时停止。保存和取消只影响草稿，不写文件或改写已开始的运行；使用前需绑定输出目录。

已保存流程可从步骤清单、流程图或长流程大纲选择「用 AI 修改此步」。原任务描述保留，单步要求单独保存；先核对发送内容，再查看实际原值／新值并采纳。宿主拒绝其他步骤、子步骤、结构和静态资源的变动，基线或绑定变化后必须重新核对。不采纳、失败、取消和重开保留要求，采纳与撤销只影响草稿，不产生运行；要扩大修改范围需明确选择「改为修改完整任务」。动态引用和可信脚本的实际影响仍需在执行前检查。

点击右上角「打开网页面板」即可在主窗口右侧输入网址、查看和操作网页，无需先运行流程。网页按 1920 像素桌面宽度排版，等比缩放至面板，高度随可视区域调整；窄面板中文字也会缩小。在流程资源中选择 FlowArk 内置浏览器后，可运行或逐步调试。收起面板、最小化工作台后任务继续；恢复窗口后仍在原网页。系统休眠或明确退出会停止任务，恢复后不自动重放。当前使用复杂表单验证功能，招聘站点校准暂停。

休眠会撤销尚未完成的运行请求，恢复后需要重新发起；旧的计划触发和重跑确认不会继续创建任务。若本地记录写入失败，仍会停止实际执行资源，并保留存储故障和最后保存状态供核对。

动作库可搜索并直接添加打开网页、填写、点击、勾选、下拉选择等 12 种网页动作。“添加到”选择主流程、条件分支或循环体，连续添加保持该位置；目标位置删除后需重新选择。上传和下载支持表单填写文件信息。

选中步骤后可在前面/后面插入动作、复制包含子步骤的节点，或移动到明确的分支位置。移动和删除会检查输出引用，避免破坏作用域。工具栏可撤销/重做当前打开草稿的最近 100 次编辑，保存后仍可撤销并再次保存；关闭或重新进入编辑器会清空历史。输入框使用原生文本撤销，画布使用 ⌘/Ctrl Z 和 ⌘/Ctrl Shift Z。草稿撤销不会撤销已经执行的网页或文件操作。

浏览器值字段、数据、条件/断言、循环集合和脚本输入可用“选择变量”引用运行参数或当前可访问的前序输出；循环体内可选当前项和序号。先选择来源、核对路径，再确认替换；未知输出字段可指定高级子路径，缺失会在执行时报错。运行参数支持文本、数字、布尔、空值与数组/对象，已有引用不会显示为空输入或默认勾选。

高级节点 JSON 未完成或改动 ID/类型时，保存、运行、调试、导出和会丢弃输入的切换会被阻止。修正文本，或点击“恢复节点配置”回到最后有效配置后继续。

节点高级配置中的 timeoutMs 对人工等待、条件和循环等节点同样生效。显式条件/循环预算包含内部等待和调试暂停；节点自身开始前的暂停不计入。未配置的人工、条件、循环、数据和断言节点不设置期限；HTTP、脚本、文件、Excel和浏览器节点仍默认 60 秒。超时停止当前运行并回收资源，不自动重试，也不撤销之前已完成的外部操作。

HTTP 提供方法、地址、请求头和请求体配置；文件支持目录绑定、读写、复制和 ZIP 文件列表。Excel 支持行列表格编辑、单元格类型与变量，以及模板文件、工作表和单元格映射；表格翻页保留全部数据。读取首个工作表时保留实际空行，行内空单元格为 null；引用读出数据再次写入时，行列位置和明确提供的尾部空行仍保留。普通读写只处理数据，保留模板格式请使用模板填充。切换文件或 Excel 操作会使用该操作的默认配置，可撤销恢复。复杂值和公式对象仍可通过高级值编辑。

HTTP 请求体也参与引用保护：删除或移动它引用的来源步骤、删除引用参数会被阻止。旧流程中缺失来源、越界或格式无效的引用需修正后才能保存、运行或创建计划；未知输出子字段仍在执行时核对。

上传配置引用参数中的目录时，也会在“参数与绑定”显示对应目录入口。已知目录未绑定或失效会在启动前报错；文件可以由前序步骤生成，在上传时检查文件存在、可读且位于绑定范围内。动态来源同样在上传前检查，失败不自动重试。

浏览器节点点击「从网页选取」，在右侧网页点选控件，自动填写选择器和框架路径；按 Esc 或取消退出。拾取不触发目标按钮。点击「验证定位」可检查唯一匹配并高亮；选择下拉操作后可直接读取网页选项。填写内容、网址使用表单编辑，选择器与 JSON 保留在高级配置。拾取生成的结构路径需在网页布局变化后重新验证。

运行记录可按名称或 ID 搜索，结合状态、来源筛选并翻页；进入详情再返回会保留页码与筛选。较早页面有新记录时点击“查看最新”回到最新记录。活动状态和流程最近结果独立于当前历史页，排队较多时也不会丢失。

运行详情展示当前步骤、运行耗时和脚本主动报告的处理数量，名称取自本次固定快照。普通运行结束后可直接查看已保存的脱敏输出，长内容可展开，不需要重跑。存储异常时，界面会区分最后保存的状态与宿主当前持有的活动任务；未保存的最终结果需人工核对，不会显示成成功。

运行产物会保存当次独立副本，后续覆盖或删除业务输出不改变旧副本。“定位副本”前会核对内容，副本被改动或丢失时禁用定位；旧记录没有历史副本，仍可定位当前文件并明确标注。产物默认保留。运行结束并收尾后，可在运行详情点击“预览产物清理”，核对数量和文件名后勾选确认，删除该次运行的应用内产物。业务输出原文件、运行记录和待办保留；清理失败或中断后需重新预览，不会在重开时自动删除。

本机计划可编辑间隔和时区，默认继续使用原固定版本。主动勾选“采用当前已保存的流程版本”才会更新流程、绑定和脚本依赖；保存保持原启用或暂停状态，不改变已排队或活动任务。间隔从保存时重新起算，时区用于显示时间，未保存的草稿不被采用。

导出使用当前编辑内容，未保存的修改也会包含在内，但不会替你保存本地草稿。先修正未完成的值输入，再审阅字面量和脚本；取消不生成文件。参数值和本地绑定不导出，导出生成新的 local 模板身份。

关闭窗口进入托盘；明确退出会停止本机计划。有任务时显示全部活动与排队数量，选择“继续运行”可取消退出。用户数据位置可在「设置」查看。脚本仅供可信代码使用。

脚本节点可绑定已安装的本地 JS/TS 包。运行和保存计划前固定精确版本及静态代码，运行中不安装依赖；重新保存计划才采用包的变动。

脚本执行结束后会先确认进程资源已回收，再进入后续步骤。回收无法确认时，运行记为中断并停止接收新任务，相关产物也暂不能清理。重开应用会再次核对；若仍提示遗留资源未停止，需要重启系统后再核对结果。不会自动重放。监护适用于可信脚本及普通子进程，不保证回收主动脱离进程组的代码；Windows 脚本执行暂不可用。

## 安装与开发

macOS arm64 构建输出在 `release/`。当前应用未签名、未公证，尚无正式发布渠道。


```sh
pnpm install --frozen-lockfile
pnpm setup:electron
pnpm check
pnpm dev
pnpm package:mac
```

需要 Node 24.3.0、pnpm 10.14.0。选择应用自带内核或已经安装的本机浏览器，不额外下载自动化浏览器。

贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。详细需求、架构、契约说明和验收资料统一由治理仓库管理，不在客户端复制维护。

构建会替换 dist 目录，请先完成构建，再运行依赖它的本地运行或桌面测试。

本轮模板与通用平台回归命令：

```sh
pnpm test:runtime
pnpm test:embedded-pointer
pnpm test:script-editor
pnpm test:flow-outline
pnpm test:excel-mapping
pnpm test:desktop
FLOWARK_TEST_EXECUTABLE=/absolute/path/FlowArk.app/Contents/MacOS/FlowArk pnpm test:install
FLOWARK_TEST_EXECUTABLE=/absolute/path/FlowArk.app/Contents/MacOS/FlowArk pnpm test:template-parameters
```

桌面测试串行执行；确认上一脚本的隔离实例退出后，再启动下一项。`test:embedded-pointer` 使用虚构框架页面核对滚动后的点击、输入、遮挡、取消与单次动作回执。

`test:script-editor` 验证 JS/TS 语法检查、脚本草稿保存/放弃、输入与超时校验，以及真实运行的历史输出；预览和语法检查不会执行脚本。

`test:flow-outline` 验证真实 40 步流程的搜索／折叠、条件和循环实例、草稿与固定快照隔离、详情返回及延迟状态；结束时取消自身未完成的运行并确认测试实例退出。

`test:excel-mapping` 验证字段冲突、预览失效、保存与放弃、静态和运行期来源、不可变快照，以及真实 Worker 工作簿输出与不覆盖已有文件。Excel 映射消费 contracts-v0.10.0，包内保留规范副本和校验摘要。

`test:ai-step-edit` 使用本机 HTTP 模型夹具，验证真实任务/IPC/宿主的单步范围、补问、取消、差异、采纳/撤销、基线冲突、大纲返回及串行重开。该检查不代表真实 DeepSeek/OpenAI 调用通过。

完整业务／表单演示通过模板仓库的 `pnpm test:client` 验证，仅消费标准包和安装版公共接口。客户端保留最小生命周期、IPC、编辑器与进程夹具。本轮未重新验收所有历史桌面脚本或外部浏览器。

内置网页回收无法确认时，运行记录为中断并停止接收新任务。请完整退出并重开应用，核对外部结果后再手动运行；不会自动重放。


当前为未正式发布的开发版本，不保留旧客户端、旧 JSON 模板或旧业务数据的兼容路径。开发数据清理只通过显式维护工具执行，凭据、通用设置和浏览器登录态保留。

0.2.1 开发候选统一导入导出：自定义流程、修改后的模板流程和模板库均使用「导出 ZIP」，默认文件名对应包内清单。自定义流程导出参数结构、逻辑目录／浏览器资源及默认禁止的写入授权；重新导入后填写入口参数、重新绑定资源并授权即可执行。模板库导出原包；编辑器导出新的本地模板身份，不携带实例值、路径、凭据或历史。动态上传目录及未静态打包的脚本依赖需先整理再导出。
