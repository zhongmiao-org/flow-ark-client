# FlowArk · 序舟

通用的本地 RPA 工作台，用于编排、运行和查看自动化流程。当前为 **macOS Apple Silicon 0.1.21 运行产物副本预览版**。

## 使用

打开 FlowArk 后，运行「第一个流程」验证本地执行。编辑器右侧提供通用节点、参数和资源绑定；业务字段来自模板包，通过独立的「实例配置」填写。普通流程不显示招聘配置。

模板库目前含 BOSS、智联两个本地模板。真实网站适配与业务验收尚未完成，程序会阻止外发；没有上线模板商店。Chrome 的表单与上传通用流程已验证；macOS Chrome 153.0.8010.48 存在原生下载恢复崩溃，当前明确阻止自动下载，尚未修复该浏览器问题。Firefox、Safari、Windows 尚未验收。

编辑器点击「逐步调试」，运行会在首个节点前暂停。「执行下一步」实际执行一个节点入口，并显示下一个位置与输出预览；条件和循环会进入实际子路径。「继续」连续运行，「取消」停止并回收本次资源。运行绑定固定快照，修改草稿不会改变已开始的调试；失败不会自动重放。

点击右上角「打开网页面板」即可在主窗口右侧输入网址、查看和操作网页，无需先运行流程。网页按 1920 像素桌面宽度排版，等比缩放至面板，高度随可视区域调整；窄面板中文字也会缩小。在流程资源中选择 FlowArk 内置浏览器后，可运行或逐步调试。收起面板、最小化工作台后任务继续；恢复窗口后仍在原网页。系统休眠或明确退出会停止任务，恢复后不自动重放。当前使用复杂表单验证功能，招聘站点校准暂停。

动作库可搜索并直接添加打开网页、填写、点击、勾选、下拉选择等 12 种网页动作。“添加到”选择主流程、条件分支或循环体，连续添加保持该位置；目标位置删除后需重新选择。上传和下载支持表单填写文件信息。

选中步骤后可在前面/后面插入动作、复制包含子步骤的节点，或移动到明确的分支位置。移动和删除会检查输出引用，避免破坏作用域。工具栏可撤销/重做当前打开草稿的最近 100 次编辑，保存后仍可撤销并再次保存；关闭或重新进入编辑器会清空历史。输入框使用原生文本撤销，画布使用 ⌘/Ctrl Z 和 ⌘/Ctrl Shift Z。草稿撤销不会撤销已经执行的网页或文件操作。

浏览器值字段、数据、条件/断言、循环集合和脚本输入可用“选择变量”引用运行参数或当前可访问的前序输出；循环体内可选当前项和序号。先选择来源、核对路径，再确认替换；未知输出字段可指定高级子路径，缺失会在执行时报错。运行参数支持文本、数字、布尔、空值与数组/对象，已有引用不会显示为空输入或默认勾选。

HTTP 提供方法、地址、请求头和请求体配置；文件支持目录绑定、读写、复制和 ZIP 文件列表。Excel 支持行列表格编辑、单元格类型与变量，以及模板文件、工作表和单元格映射；表格翻页保留全部数据。切换文件或 Excel 操作会使用该操作的默认配置，可撤销恢复。复杂值和公式对象仍可通过高级值编辑。

HTTP 请求体也参与引用保护：删除或移动它引用的来源步骤、删除引用参数会被阻止。旧流程中缺失来源、越界或格式无效的引用需修正后才能保存、运行或创建计划；未知输出子字段仍在执行时核对。

上传配置引用参数中的目录时，也会在“参数与绑定”显示对应目录入口。已知目录未绑定或失效会在启动前报错；文件可以由前序步骤生成，在上传时检查文件存在、可读且位于绑定范围内。动态来源同样在上传前检查，失败不自动重试。

浏览器节点点击「从网页选取」，在右侧网页点选控件，自动填写选择器和框架路径；按 Esc 或取消退出。拾取不触发目标按钮。点击「验证定位」可检查唯一匹配并高亮；选择下拉操作后可直接读取网页选项。填写内容、网址使用表单编辑，选择器与 JSON 保留在高级配置。拾取生成的结构路径需在网页布局变化后重新验证。

运行产物会保存当次独立副本，后续覆盖或删除业务输出不改变旧副本。“定位副本”前会核对内容，副本被改动或丢失时禁用定位；旧记录没有历史副本，仍可定位当前文件并明确标注。副本暂不自动清理。

关闭窗口进入托盘；明确退出会停止本机计划。用户数据位置可在「设置」查看。脚本仅供可信代码使用。

无需账号的浏览器练习见 `examples/simple-web-form.template.json`：从应用导入后，选择 FlowArk 内置浏览器，并将文件绑定 `output` 指向练习输出目录，再手动运行。流程向 Selenium 官方测试表单提交固定的虚构文本，读取回执，生成 Excel 和截图；不需要招聘账号或 AI 配置。会在输出目录生成或覆盖 `simple-web-result.xlsx`，请使用独立目录。

脚本节点可绑定已安装的本地 JS/TS 包。运行和保存计划前固定精确版本及静态代码，运行中不安装依赖；重新保存计划才采用包的变动。

复杂表单练习：运行 `pnpm forms:serve`，打开 <http://127.0.0.1:4178>，可测试文本、单复选、下拉多选、日期、异步联动、自定义控件和文件上传。页面提供虚构样本文件与配套流程下载；将样本保存到独立目录，导入流程后绑定 FlowArk 内置浏览器 和文件目录 `work`。此流程需要 0.1.5 新增的表单动作，旧版 0.1.4 不支持；`pnpm test:forms` 验证真实宿主，`pnpm test:debug` 验证桌面单步调试与浏览器上传。

## 安装与开发

macOS arm64 构建输出在 `release/`。当前应用未签名、未公证，尚无正式发布渠道。

```sh
pnpm install --frozen-lockfile
pnpm setup:electron
pnpm check
pnpm dev
pnpm package:mac
```

需要 Node 24.3.0、pnpm 10.14.0。选择应用自带内核或已经安装的本机浏览器，不额外下载自动化浏览器。

贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。详细需求、架构、契约说明和验收资料统一由治理仓库管理，不在客户端复制维护。

浏览器回归默认使用内置网页；本机 Chrome 兼容检查需显式运行 `pnpm test:chrome` 或 `pnpm test:chrome-recovery`。

元素拾取验证：`pnpm test:picker` 覆盖内置网页定位与取消，`pnpm test:picker-ui` 覆盖从空白草稿直接搭建 12 种网页动作、保存和逐步执行，`pnpm test:picker-lifecycle` 验证点选中的关闭、恢复与重复使用。

动作库验证：`pnpm test:action-library` 覆盖搜索、分类、键盘添加、嵌套分支和已删除添加位置。

编排布局验证：`pnpm test:editor-layout` 覆盖网页面板展开、收起、窗口尺寸变化，以及选中节点、未保存配置和网页会话的保留。小窗口打开网页时，节点库移至画布上方，可横向滚动选择节点。

网页宽度验证：`pnpm test:browser-viewport` 覆盖首次后台导航、桌面布局、原生点击、窗口调整及会话保留。

值与变量配置验证：`pnpm test:value-editor` 覆盖类型化参数、作用域候选、引用选择/取消、撤销、保存重开与内置表单实际执行。

资源配置验证：`pnpm test:resource-editor` 覆盖 HTTP、文件、ZIP、Excel 配置与实际产物、分页及撤销、内置表单上传、HTTP 失败不重试和路径越界阻止。

流程编辑验证：`pnpm test:flow-editing` 覆盖插入、复制、移动、引用保护、撤销/重做、保存重开与调试快照隔离。

产物历史验证：`pnpm test:artifact-history` 覆盖独立副本、来源删除、重开后的新旧记录、内容改动与文件丢失，以及定位按钮与宿主复验。测试使用独立临时数据。
