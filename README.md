# FlowArk · 序舟

通用的本地 RPA 工作台，用于编排、运行和查看自动化流程。当前为 **macOS Apple Silicon 0.1.9 元素拾取预览版**。

## 使用

打开 FlowArk 后，运行「第一个流程」验证本地执行。编辑器右侧提供通用节点、参数和资源绑定；业务字段来自模板包，通过独立的「实例配置」填写。普通流程不显示招聘配置。

模板库目前含 BOSS、智联两个本地模板。真实网站适配与业务验收尚未完成，程序会阻止外发；没有上线模板商店。Chrome 的表单与上传通用流程已验证；macOS Chrome 153.0.8010.48 存在原生下载恢复崩溃，当前明确阻止自动下载，尚未修复该浏览器问题。Firefox、Safari、Windows 尚未验收。

编辑器点击「逐步调试」，运行会在首个节点前暂停。「执行下一步」实际执行一个节点入口，并显示下一个位置与输出预览；条件和循环会进入实际子路径。「继续」连续运行，「取消」停止并回收本次资源。运行绑定固定快照，修改草稿不会改变已开始的调试；失败不会自动重放。

点击右上角「打开网页面板」即可在主窗口右侧输入网址、查看和操作网页，无需先运行流程。在流程资源中选择 FlowArk 内置浏览器后，可运行或逐步调试。收起面板、最小化工作台后任务继续；恢复窗口后仍在原网页。系统休眠或明确退出会停止任务，恢复后不自动重放。当前使用复杂表单验证功能，招聘站点校准暂停。

浏览器节点点击「从网页选取」，在右侧网页点选控件，自动填写选择器和框架路径；按 Esc 或取消退出。拾取不触发目标按钮。点击「验证定位」可检查唯一匹配并高亮；选择下拉操作后可直接读取网页选项。填写内容、网址使用表单编辑，选择器与 JSON 保留在高级配置。拾取生成的结构路径需在网页布局变化后重新验证。

关闭窗口进入托盘；明确退出会停止本机计划。用户数据位置可在「设置」查看。脚本仅供可信代码使用。

无需账号的浏览器练习见 `examples/simple-web-form.template.json`：从应用导入后，选择 FlowArk 内置浏览器，并将文件绑定 `output` 指向练习输出目录，再手动运行。流程向 Selenium 官方测试表单提交固定的虚构文本，读取回执，生成 Excel 和截图；不需要招聘账号或 AI 配置。会在输出目录生成或覆盖 `simple-web-result.xlsx`，请使用独立目录。

脚本节点可绑定已安装的本地 JS/TS 包。运行和保存计划前固定精确版本及静态代码，运行中不安装依赖；重新保存计划才采用包的变动。

复杂表单练习：运行 `pnpm forms:serve`，打开 <http://127.0.0.1:4178>，可测试文本、单复选、下拉多选、日期、异步联动、自定义控件和文件上传。页面提供虚构样本文件与配套流程下载；将样本保存到独立目录，导入流程后绑定 FlowArk 内置浏览器 和文件目录 `work`。此流程需要 0.1.5 新增的表单动作，旧版 0.1.4 不支持；`pnpm test:forms` 验证真实宿主，`pnpm test:debug` 验证桌面单步调试与浏览器上传。

## 安装与开发

macOS arm64 构建输出在 `release/`。当前应用未签名、未公证，尚无正式发布渠道。

```sh
pnpm install --frozen-lockfile
pnpm setup:electron
pnpm check
pnpm dev
pnpm package:mac
```

需要 Node 24.3.0、pnpm 10.14.0。选择应用自带内核或已经安装的本机浏览器，不额外下载自动化浏览器。

贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。详细需求、架构、契约说明和验收资料统一由治理仓库管理，不在客户端复制维护。

浏览器回归默认使用内置网页；本机 Chrome 兼容检查需显式运行 `pnpm test:chrome` 或 `pnpm test:chrome-recovery`。

元素拾取验证：`pnpm test:picker` 覆盖内置网页定位与取消，`pnpm test:picker-ui` 覆盖从空白草稿搭建、保存和逐步执行。
