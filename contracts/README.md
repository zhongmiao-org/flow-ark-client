# 0.50.0 连续有限批次候选

2026-10-21，继承已封存0.49.0，追加通用`entry-batches-v1`和入口可选`batching`声明。当前为候选，未发布tag、未被客户端采用；[规范与消费者门槛](../../docs/client/finite-run-continuation.md)持续记录实际阶段，不能将机器资料当作自动循环或业务完成。

作者入口及正式包入口都必须通过固定结果Schema关系校验，能力与三字段声明同时存在。包2.0/SDK1.0和旧节点保持，不给脚本增加创建Run接口。首批只支持可复用模板/作者入口；一次性桌面、工具、修复目标、逐步调试、定时/历史重跑不隐式获得连续授权。

28项线格式定义覆盖字段映射/有限设置、固定范围及进程证明、唯一Run链接/准入与结果证明、预检扩展、会话视图、有界游标及两种停止回执；RunState仅沿用旧定义。会话监督、稳定授权范围与每批完整RunReview、原子登记、取消/迟到、最终秘密处理、引用保护及恢复不重放由规范约束，形状或纯关系校验不证明宿主已执行这些规则。

新批次调度时限不强杀当前Run。每批释放原单槽；新未决操作/失败/来源变化停止，只有当前准确完整结果的完成决策可记录目标完成。本地限制、进度不变、空队列或普通Run成功不等于外部终点。重开只读原记录，不恢复进程许可或自动续跑。

候选未改变单Run1000项/8MiB约束或做数据截断；预算预检与完整持久化仍须独立实现。客户端采用、原生可视化配置/导出/空白复导、完整竞争矩阵，以及BOSS真实网站150次招呼上限与回复后附件/有序聊天分别验收。
