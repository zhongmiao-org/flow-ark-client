# 飞书多维表格

## 适用与事实

先确认平台、业务对象、表格视图、目标字段类型及允许范围。已提供的信息不要重复追问。用户只说飞书时，区分多维表格、电子表格、文档或消息。不能因名称相近套用本 Skill。

此文是平台操作知识，不包含具体客户映射、网址、坐标、选区尺寸或登录信息。使用安装客户端的真实 SDK、节点 Schema 与权限；不得编造方法、DOM、私有 store 或接口。生成前检查所需能力；缺失能力报告客户端缺口，不能通过加提示词掩盖。

## 拟人模式优先边界

当前工程声明 `executionMode: desktop-human-v1` 或用户要求拟人操作时，下列 DOM/网页语义路径不适用。所有目标证据来自 FlowArk 正式桌面观察的可见内容、辅助功能或截图，操作仅经已绑定窗口的鼠标与键盘；不调用任何飞书 API，不读取页面内部数据、不执行页面脚本、不拦截网络、不连接浏览器调试协议。文本、下拉、人员、保存和重开均使用这一路径，失败不切驱动或接口重放。

由 FlowArk 自身采集当前表格和字段证据、在同一对话展示映射和范围，用户只确认业务规则，不要求用户配置 RPA、选择器或坐标。先证明少量有效记录的输入、保存、界面回读和真实重开，再经确认扩展剩余范围。原始 Excel 和目标已有数据不为验收而清空；本地应用重置不授予飞书删除或覆盖许可。没有明确唯一匹配和保存证据时保留待办或 unknown。

开发与验收禁用用户 Key 时，源码不得自行调用供应商补齐观察；需要视觉判断时只经正式 `desktop.decide` 和宿主已隔离的本机子智能体连接，不读取或回退真实凭据。缺少该通道时返回真实能力缺口。子智能体只能响应 FlowArk 的规划、代码和判断请求，不能直接操作浏览器或用外部脚本完成录入。

## 定位与执行路径

先识别 DOM、辅助功能和 Canvas 的可用程度。优先角色、可访问名称、关联标签、当前弹层/行/字段容器，要求目标唯一。DOM 只能采用当前页面已验证的属性；尚无通用稳定 CSS 类名可承诺。无名 input 必须在已识别弹层内结合相邻标签唯一定位，不选页面第一个 input。

Canvas 网格不假定存在单元格 DOM。坐标、缩放、表头、行距留在工程绑定并在当前视图核对，不能从本机历史套用。选定驱动在副作用前确定，unknown 后不切驱动重放。系统输入依赖前台焦点、剪贴板和空闲输入，浏览器语义驱动是否可用须独立证明。

所有动作采用 fresh 观察、实际条件等待和有界超时；模型声称 verified、按键发出或 native performed 均不等于业务成功。观察过期、目标变化、输入受干扰时停止；环境错误交回客户端诊断，不盲目重写业务源码。

## 文本与网格编辑

区分网格选择态和单格编辑态。先证明最小循环：定位一格→打开对应编辑器→确认唯一可编辑控件→输入→完成提交→离开编辑态→重新读取实际格值。input/fill 设置值不代表控件已提交；提交按该控件实际支持的 Enter、确认按钮或失焦方式验证，不统一模拟事件。

不得默认 TSV 多列粘贴会分格；先用允许的最小范围证明字段分布。电话按来源类型和显示格式保留前导零，不擅自数字化。业务映射、空白范围、允许覆盖与保护字段由工程确定。

空白单格复制无文本不能作为空白证明；可在当前页面已证明的完整上下文矩形读取后提取单格。矩形尺寸与工程预期严格一致，不把编辑器剪贴板文字当网格数据。Tab 往返或拖选仅在当前视图证明有效后使用，不写死导航序列和选区尺寸。

## 已有单选与多选下拉

打开目标字段对应弹层，确认弹层身份、当前选值、搜索框及选项类型。按确切名称搜索已有项，等待结果稳定并要求唯一准确匹配；提交后关闭弹层并回读实际字段值。多选核对完整选项集合及保留项，不能无意替换已有值。

新增选项是独立副作用：仅在业务明确允许创建、已有精确项不存在、当前确有创建入口时生成。记录创建意图，核对名称与结果后再选择；无权限或无入口转待办，不擅创建近似项。

## 搜索与人员

只在已打开的正确 picker 内搜索。输入后等待当前查询对应的候选或明确空结果；不以旧候选、第一项、重名或模糊名称猜选。人员需要来源允许的唯一身份信息，不能猜邮箱、跨组织人员或通过反复关键词探测补齐。

无唯一准确匹配：持久记录待办（字段/行的本地引用、原因、原始预期），退出搜索器，证明未产生关联，再继续下一输入框。待办必须由宿主真实保存，日志不算。人员通知等额外副作用独立处理；没有相应授权时不能确认会通知的关联。

有效预期保留该待办格未填，原来源保持不变；结果分别统计写入、待办和原始差异。恢复不重新搜索或自动消除待办，用户处理后仅对确认范围重新核验。

## 群组

群组 picker 与人员 picker 分开识别。已观察版本有“请选择群组”及“搜索群组”相邻标签，无名搜索框须结合弹层范围唯一定位；这些是有条件观察，必须在当前页面确认。真实已有群关联和提交回读尚未通过完整验收。

无精确匹配记待办；创建群、邀请、关联和发消息不能从搜索或填写授权推导。保护字段完全不写，不为验证而建立关联。

## 提交、保存与重新读取

逐个或已证明有效的小批次写入，逐批回读；宿主持久化意图、进度、成功回执及 unknown。结果不明先只读核对，不换业务键、来源或实例重放。取消不等于动作未发生。

Command+S 在多维表格可能保存视图配置，按键成功不能证明记录持久化；浏览器另存为或书签标识也不算。必须核对当次业务页面的正向保存/同步证据、允许范围实际值和保护范围。

重新打开/刷新通过驱动支持的真实生命周期和业务对象身份取证，再 fresh 回读。不能仅凭新 observationId、固定延时或是否捕获瞬时停止按钮判定刷新。驱动缺少可靠证据时报告未通过，保留未知状态不重复刷新/填写。重开后成功字段一致、待办格未误填、保护字段不变，再运行不得重复追加。

## 验证边界与问题反馈

历史已条件性验证文本格输入/提交/范围回读、单选过滤及人员/群组匿名搜索；不能扩大成所有飞书版本保证。完整填写、人员与群组真实选择、写后保存和重开防重尚未联合通过。每个工程先验证最小控件循环再扩大范围。

定位、输入、提交或回读失败时记录客户端/Skill 版本、控件类型、错误阶段与脱敏证据，用户可主动向客户端 GitHub 提 Issue；不自动上传业务内容、凭据或登录态。

API Key 产生的费用由用户自行承担；本 Skill 不授权模型调用或付费重试。
